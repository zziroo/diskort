Diskort İndir

Kod imzalama politikası

Son güncelleme: 30 Eylül 2026 · English below

Durum: Diskort'un Windows dosyaları şu an imzasız yayınlanıyor. Bu yüzden Windows, kurulum dosyasını açarken “Bilinmeyen yayıncı” uyarısı gösterebilir. Kod imzalama henüz açılmadı ve SignPath Foundation'a başvurulmadı; aşağıdaki politika, imzalama açıldığında uygulanacak düzeni anlatır.

İmzalama açıldığında ücretsiz kod imzalama SignPath.io tarafından sağlanacak, sertifika SignPath Foundation'a ait olacak. Windows için yayınlanan Diskort dosyaları (Diskort.exe ve Diskort-Setup-<sürüm>.exe) bu sertifikayla imzalanacak ve Windows'ta yayıncı olarak “SignPath Foundation” görünecek.

Nasıl derlenir ve imzalanır

  • Kaynak kodun tamamı herkese açıktır ve MIT lisanslıdır: github.com/zziroo/diskort.
  • İmzalanan her dosya, depodaki etiketlenmiş (v*) bir sürümden GitHub Actions üzerinde (.github/workflows/release.yml, GitHub'ın barındırdığı sunucular) otomatik olarak derlenir. Elle derlenmiş dosyalar imzalanmaz.
  • SignPath, dosyanın gerçekten bu depodaki bu iş akışından geldiğini imzalamadan önce teknik olarak doğrular.
  • Her imzalama isteği aşağıdaki onaylayıcı tarafından tek tek elle onaylanır.
  • Yalnızca Diskort'un kendi kaynak kodundan üretilen dosyalar imzalanır. İçerdiği üçüncü taraf bileşenler (Electron/Chromium kütüphaneleri, yerel modüller) imzalanmaz.

Roller

  • Yazarlar (committers): @zziroo (depo sahibi). Depoya yalnızca depo sahibi doğrudan yazabilir.
  • Gözden geçirenler (reviewers): @zziroo. Dışarıdan gelen her katkı (pull request) birleştirilmeden önce gözden geçirilir.
  • Onaylayıcılar (approvers): @zziroo. Her imzalama isteğini SignPath'te onaylar.

Tüm ekip üyeleri GitHub ve SignPath hesaplarında çok adımlı doğrulama (MFA) kullanır.

Gizlilik

Diskort bir sesli sohbet ve mesajlaşma uygulamasıdır; işlevi gereği yalnızca kullanıcının giriş yaptığı Diskort sunucusuna bağlanır (varsayılan diskort.ziroo.net, ses/görüntü için lk.ziroo.net; kullanıcı başka bir sunucu da ekleyebilir). Güncellemeleri diskort.ziroo.net üzerinden denetler ve dosyaları GitHub'dan indirir. Sohbette paylaşılan YouTube bağlantıları, kullanıcı oynatınca youtube-nocookie.com oynatıcısıyla gösterilir; sohbetteki GIF'ler GIPHY'nin sunucularından yüklenir. “Oynadığım oyunu göster” ayarı açıkken açık olan oyunun adı ve ikonu Diskort sunucusuna gönderilir (ayar kapatılabilir). Geri bildirim ve ekran görüntüsü yalnızca kullanıcı gönderdiğinde iletilir. Reklam, izleme ya da analiz aracı yoktur ve bunların dışında hiçbir sisteme veri gönderilmez. Ayrıntılar: Gizlilik.

Kaldırma

Windows'ta Ayarlar → Uygulamalar → Yüklü uygulamalar → Diskort → Kaldır. Ayarlar ve oturum bilgisi %APPDATA%\Diskort klasöründe kalır; tamamen silmek için bu klasörü silebilirsin.

İletişim

İmzalı bir dosyayla ilgili şüphe ya da kötüye kullanım bildirimi için: diskort@ziroo.net ya da GitHub Issues.

Code signing policy

Status: Diskort's Windows files are currently published unsigned. Windows may therefore show an “Unknown publisher” warning when the installer is opened. Code signing has not been enabled yet and no application has been submitted to SignPath Foundation; the policy below describes how signing will work once it is enabled.

Once enabled, free code signing will be provided by SignPath.io, with a certificate by SignPath Foundation. The Windows files published for Diskort (Diskort.exe and Diskort-Setup-<version>.exe) will be signed with that certificate, and Windows will show “SignPath Foundation” as the publisher.

How releases are built and signed

  • All source code is public and MIT licensed: github.com/zziroo/diskort.
  • Every signed file is built automatically by GitHub Actions on GitHub-hosted runners (.github/workflows/release.yml) from a tagged (v*) commit of that repository. Locally built files are never signed.
  • SignPath technically verifies that each file originates from that workflow in that repository before signing it.
  • Every signing request is manually approved by the approver listed below.
  • Only files built from Diskort's own source code are signed. Bundled third-party components (Electron / Chromium libraries, native modules) are not signed with this certificate.

Team roles

  • Committers and reviewers: @zziroo (repository owner). Only the owner has write access; every external contribution is reviewed before it is merged.
  • Approvers: @zziroo.

All team members use multi-factor authentication for GitHub and SignPath.

Privacy policy

Diskort is a voice chat and messaging app. It connects only to the Diskort server the user signs in to (by default diskort.ziroo.net, and lk.ziroo.net for voice/video; users may add other servers), which is required for its function. It checks for updates via diskort.ziroo.net and downloads update files from GitHub. YouTube links shared in chat are embedded with the youtube-nocookie.com player when the user plays them; GIFs shown in chat are loaded from GIPHY's servers. While the “show the game I'm playing” setting is on, the name and icon of the running game are sent to the Diskort server (the setting can be turned off). Feedback and screenshots are sent only when the user submits them. There is no advertising, tracking or analytics, and apart from the above this program will not transfer any information to other networked systems. Details (Turkish): Privacy.

Uninstalling

Windows: Settings → Apps → Installed apps → Diskort → Uninstall. Settings and the login session remain in %APPDATA%\Diskort; delete that folder to remove them as well.

Contact

To report a concern or abuse related to a signed file: diskort@ziroo.net or GitHub Issues.
